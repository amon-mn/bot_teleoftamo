# Instruções para agentes de IA

Regras que qualquer agente de IA (Claude, Copilot, Cursor, Codex, etc.) deve seguir ao trabalhar neste repositório.

## Commits e Pull Requests

- **Nunca** adicionar linhas de coautoria/atribuição de IA em mensagens de commit ou descrições de PR — por exemplo, `Co-Authored-By: Claude <...>`, `Co-Authored-By: <qualquer-IA>`, "🤖 Generated with ..." ou variações equivalentes.
- Mensagens de commit e descrições de PR devem conter apenas o conteúdo relevante à mudança em si.
